Privacy is the default, not a setting.

What the CLI processes

The CLI reads the JSONL events, repository files, and test artifacts you explicitly point it at. Processing happens on your computer. It does not send events, hashes, file names, prompts, file contents, or usage telemetry to us. Prompts and file contents are not included in exported ledgers.

What the website processes

The browser demo parses pasted events and hashes files locally with the Web Crypto API. That data does not leave the browser and is not saved after the page closes. The service worker may cache public site assets so documentation and the demo remain available offline.

License data

If you buy or restore the Team policy kit, the license token and last verification verdict are stored in your browser’s localStorage. Verification sends only that token to the Sociobot API at api.sociobot.in, at most once per day after a valid check. Sociobot/Dodo is the merchant of record and processes checkout details under its own legal terms.

Local storage controls

Saved team policy presets remain on your device. Clear this site’s storage in your browser to remove the token, cached verdict, policies, and offline cache. No analytics, advertising identifiers, third-party fonts, or tracking scripts are used.

Contact

For privacy questions, open a non-sensitive issue in the project repository. Do not attach private ledgers, license tokens, or repository data.
